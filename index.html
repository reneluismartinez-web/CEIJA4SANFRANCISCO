Cómo usar el mapa

Una guía rápida para visitantes y estudiantes.

  1. Como visitante podés explorar toda la información sin modificarla.
  2. Como estudiante ingresás con tu nombre y podés agregar puntos.
  3. Cada punto nuevo queda asociado a tu usuario técnico de Firebase.
  4. Podés editar o eliminar únicamente tus propios puntos.
  5. El docente puede administrar todos los puntos y las categorías.
  6. Usá el buscador para encontrar rápidamente un lugar entre todos los cargados.
